# Code 📚

> **来时路** —— 记录初涉代码世界的足迹

这是一个个人编程学习的历史档案仓库，成型于约 10 年前，完结于 2020 年。它记录了我初步接触代码世界时走过的路，包括各种编程语言的学习笔记、算法练习、以及探索不同技术领域的尝试。

**🗄️ 本仓库已归档，不再更新。**

## ✨ 精选内容

### 🔢 C 语言经典算法

- `01bag_*.c` - 0/1 背包问题的多种解法（递归、动态规划、贪心、分支限界、回溯）
- `eightqueen*.c` - 八皇后问题
- `Huffman.c` - 霍夫曼编码
- `hanoi.c` - 汉诺塔问题
- `lcs.c` - 最长公共子序列
- `matrixchain.c` - 矩阵链乘法
- `merge_sort.c` / `quicksort.c` - 排序算法
- `3Dcolorheart.c` / `flashheart.c` - 趣味爱心图案打印 ❤️

- `py-game/` - Pygame 游戏项目
- `pythonSocket/` - Socket 网络编程
